## 1. 问题与结论

- 原完成条件是用户选中过全部台词，未要求实际听完对话音频。
- 现改为四段台词音频都触发 `ended` 后才完成探索步骤；开始播放但未播完不计入，重复播放同一句只计一次。
- 台词选择只负责展开拼音、翻译和词语说明，不再影响步骤完成状态。
- 进度文案从 `explored` 改为 `listened`，完成反馈同步改为 `Every line heard`。
- 音频失败提示明确说明需要重试并完整播放，不再误导用户可以跳过音频完成该步骤。

## 1. 问题与结论

- 原流程完成后只显示通用课程完成反馈，用户无法知道本次对话覆盖了多少自己的台词，也无法回听刚才录制的内容。
- 角色练习现在按用户回合保留多段录音；完成后生成专用 `Practice feedback`，评价对话回合完整度和真实录音覆盖率。
- 当前纯前端阶段没有语音识别能力，因此不展示虚假的发音分数；反馈明确引导用户比较声调走向、音节时长和停顿位置。
- 每个用户回合提供标准音频播放按钮和独立的用户录音播放器，同时显示实际录音时长；未录制的异常跳过回合会明确显示缺失状态。
- 标准音频回放结束不会重新推进课程状态；用户可以完成逐句对比后 Continue，也可以 Practice again 换角色重练。

## 4. 已知边界

- 用户录音只存在于当前浏览器内存和当前练习会话；刷新页面、重新练习或离开组件后会释放，暂不跨会话保存。
- 当前评价不分析音素、声调准确率或语速质量；这类结论必须等待后续可靠的语音分析能力。
- 标准音频仍是明确标记的生成占位素材，正式发布前必须替换为原创真人录音。

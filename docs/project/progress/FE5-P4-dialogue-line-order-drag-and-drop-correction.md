## 1. 问题与结论

- 原交互通过每行的上移、下移按钮调整顺序，操作次数多，也不能直接表达“把这句放到这里”的意图。
- `DialogueLineOrder` 现改为纵向拖放排序；整行保持稳定尺寸，右侧提供独立拖动把手，拖动中通过边框、背景和阴影反馈当前状态。
- 排序使用 `@dnd-kit/react` 的 sortable 能力，并为纵向列表采用 `closestCorners` 碰撞检测，改善鼠标和触控指针经过相邻行时的命中体验。
- 拖放逻辑仍由公共 `useOrderingInteraction` hook 管理；组件只提交起点、终点索引，纯函数 `reorderItems` 负责不可变重排，课程答案协议未改变。
- 拖动把手支持键盘操作：聚焦后使用空格键开始或结束拖动，通过方向键移动；提交后所有把手和检查按钮统一锁定。
- 未引入后端状态或持久化，课程顺序仍只存在于当前前端学习会话中。

## 4. 后续复用边界

- 后续句子排序、步骤排序等线性练习可复用 `useOrderingInteraction` 与 `reorderItems`，但课程组件应保留自己的行内容和答案反馈。
- 若后续出现跨分组拖放或拖放到语义槽位，应建立新的交互协议，不在当前线性排序 hook 中叠加分组状态。
- 当前对话文本和占位音频继续遵守原创替换要求；本次校准没有引入教材 OCR 内容或版权受限素材。

## 1. 问题与结论

- 普通声调题、听辨题和课末检查中的部分题目只配置了三个候选声调，选项不完整。
- 选项按钮内的 SVG 受到 flex 尺寸收缩，卡片虽然较大，但曲线只显示为很短的线段。
- 现已统一显示第一至第四声，并以 2×2 布局承载四个选项。
- 声调曲线使用固定高度、占满卡片宽度的画布，成为选项中的主要识别信息。

## 2. 实现约束

- `PinyinLessonSchema` 将 `optionToneNumbers` 从 2-4 项收紧为恰好 4 项。
- 正式课程和第二份未发布 fixture 的所有声调题均显式配置 `[1, 2, 3, 4]`。
- 新增 `ToneOptionContour`，统一普通选择、听辨视觉降级和课末检查的选项曲线尺寸。
- 移动端保持单列，`sm` 及以上使用两列，避免四列导致曲线和文字过窄。

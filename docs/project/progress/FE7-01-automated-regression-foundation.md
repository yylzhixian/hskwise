## 1. 本次结论

FE7 已建立可重复执行的 Playwright 回归基础。当前生产构建可在移动、平板和桌面三组基准视口验证目标选择、路线恢复、错题复习闭环、刷新持久化、页面边界和首批键盘语义，不再依赖人工临时注入浏览器状态。

本子阶段只完成回归基础和高信号基线修正，不代表 FE7 整体验收结束。四门课程的正确、错误、重试、退出、媒体异常和浏览器历史路径仍属于后续工作。

## 2. 自动化基础

- 新增 Playwright 配置，使用 `next start` 的生产模式作为测试服务器，固定运行于 `127.0.0.1:3100`。
- 配置 `390x844`、`768x1024`、`1440x900` 三个 Chromium 项目，并为失败保留截图、trace 和视频。
- 新增确定性的 v2 learning state fixture；测试通过正式 localStorage 协议初始化场景，不向产品路由增加 fixture query 或测试专用运行时代码。
- 新增 `test:e2e` 与 `test:e2e:headed` 命令；默认 `test` 明确限定到 `tests/unit`，避免 Bun 与 Playwright runner 互相收集用例。
- Playwright 报告、临时结果和截图目录保持忽略，不将易过期的运行产物提交为产品文件。

## 3. 首批回归范围

### 学习主流程

- 从 `/` 选择 HSK exam 目标并进入 `/learn`，验证目标、路线和初始进度。
- 用确定性状态恢复 75% 路线进度与 1 条到期复习，刷新后状态保持。
- 从 `/review` 揭示答案并选择 `I recalled it`，验证关联错题被精确解决且 `/mistakes` 统计更新。
- 选择 `Review again` 时验证中性反馈、10 分钟重排、队列保留和刷新恢复，不把主动回忆的不确定状态显示成答错。

### 响应式与语义

- `/learn`、`/mistakes`、`/review` 在三组视口均无页面级横向溢出，页面标题正确且控制台无 error。
- 每个页面生成精确视口截图，共 9 张；已人工检查固定导航、路线曲线、表格内部滚动和复习页首屏。
- 验证键盘首次 Tab 可见且聚焦 `Skip to content`。
- 验证当前主导航使用 `aria-current="page"`，复习页保持单一一级标题。

## 4. 基线修正与架构保护

- Button、Badge 和 Progress 不再使用 `transition-all`，只过渡实际需要的属性；Button 增加触控操作提示。
- Empty description 改用语义段落元素。
- 复习完成或再次安排的反馈使用 `role="status"`，保持礼貌播报，不冒充阻断错误。
- ESLint 的受限导入路径从已移除的 `src/features` 更新到当前 `views`、`components`、`courses`、`store` 和 `learning/runtime` 结构，继续约束 UI、model、state 和 adapter 的依赖方向。

## 5. 素材与版权

- 本阶段没有引入教材 OCR 内容、图片、音频或外部素材。
- 测试数据为项目状态结构的确定性模拟，不包含教材正文。
- 课程内既有生成音频仍是发布前必须替换的占位素材；本阶段未改变其登记和替换标记。

## 7. 已知限制与下一步

- 尚未自动走通四节点路线中的每门课程，也未覆盖课程退出、浏览器前进/后退和临时状态隔离。
- 尚未覆盖音频失败、麦克风拒绝、localStorage 不可用和其他异常情景。
- 当前截图覆盖路线、错题和复习页首屏；课程默认态、反馈态、完成态与媒体异常态仍需扩展。
- 键盘与 ARIA 只建立了第一批哨兵断言；焦点顺序、触控目标、对比度和 reduced-motion 仍需完整检查。
- 尚未执行课程 bundle、动态 import、不必要 Client Component 和运行性能分析。
- FE7-02 先补齐四节点课程全路径与异常场景，再进入性能和完整视觉/无障碍验收。

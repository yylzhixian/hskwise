## 1. 问题

首页 `TonePathVisual` 的曲线路径原本从第一个节点左侧开始，并在最后一个节点右下方结束。虽然节点绘制在路径上层，但路径首尾仍越过圆形边界，形成两段不应出现的短线。

## 2. 修正

- 将路径起点从 `(48, 100)` 收敛到第一个节点圆心 `(72, 100)`。
- 将路径终点从 `(672, 112)` 收敛到最后一个节点圆心 `(644, 98)`。
- 同步调整首尾贝塞尔控制点，保持四个声调节点之间的曲线连续、平滑。
- 路径仍先于节点绘制，因此首尾线帽完整隐藏在节点内部，不需要额外遮罩或运行时计算。

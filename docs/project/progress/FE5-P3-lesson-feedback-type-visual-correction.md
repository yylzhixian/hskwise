## 1. 问题与结论

- 媒体和练习完成原本使用泛化的 `info` 类型，与提醒状态共用黄色样式，不能清楚表达已经完成学习。
- Lesson Runtime 新增 `completion` 反馈类型，媒体和录音步骤完成后不再伪装成一般信息。
- footer 反馈现在按语义显示四种状态：完成为绿色、答对为蓝色、答错为红色、一般提醒为黄色。
- 每种反馈同时使用不同图标和具体反馈标题，不依赖颜色作为唯一识别方式。
- 答错反馈继续配合 `Try again`，完成、答对和信息反馈配合 `Continue`。

## 1. 三条黄金任务

### 任务一：新增场景并填写内容

步骤：

1. 打开 `/admin/studio`。
2. 在课程结构中选择目标课节。
3. 点击“新增场景”，选择场景模板。
4. 进入“内容编辑”，修改场景标题和基础属性。
5. 等待本地保存完成。

U0 基线：入口分散在大纲加号和顶部 Templates，用户难以理解新增位置；场景属性、播放器和时间轴同时出现。

U1 当前状态：统一为顶部“新增场景”，默认进入内容编辑模式；场景属性修改已进入 Travels 历史。组件内容直接编辑仍等待 U2。

### 任务二：添加或修改内容并完成预览

步骤：

1. 选择场景并进入“内容编辑”。
2. 选择或新增文本、对话、素材或互动题。
3. 修改内容和必要属性。
4. 进入“预览检查”，切换学员身份并完成一次互动。

U0 基线：没有清晰的组件插入入口，必须从 Inspector 的 Element 标签理解内部元素；功能路径被 JSON、检查和时间轴干扰，因此任务无法稳定完成。

U1 当前状态：内容与预览已经分离为独立模式；组件选择、插入和画布直接编辑仍是 U2 的阻断项。

### 任务三：制作互动时间轴

步骤：

1. 进入“动画时间轴”。
2. 新增或选择片段。
3. 拖动片段起点并调整持续时间。
4. 设置互动暂停，预览回答后继续播放。
5. 撤销和重做拖动结果。

U0 基线：时间轴、播放器和完整 Inspector 同屏，轨道可拖动但编辑对象与属性关系不清晰；操作仍暴露 action、target ID 和毫秒输入。

U1 当前状态：时间轴已有独立工作区并获得更大垂直空间；片段语言、拖动反馈、轨道组织和 50 片段性能仍等待 U3。

## 3. 状态更新位置盘点

- 课程文档唯一入口：`CourseStudioProvider` / `useCourseStudioDocument`。
- 场景 CRUD、素材、知识点、JSON 导入和音频时长回填通过 `commitProject` 写入。
- 连续场景编辑使用 `scene:<sceneId>` 合并键，600ms 静默后归档。
- 播放头、当前模式、选择对象、弹窗和时间轴视图不进入文档历史。
- 学习进度继续使用独立 `SceneProgressStore`，不进入 Travels。
- 遗留问题：Inspector、Timeline 和 Asset Library 仍直接产生完整对象，需要在 U2/U3 迁移为细粒度命令。

# 教材等级与内容密度观察

本文件记录 OCR 样本反映的方向性变化，为课程步骤长度和交互组合提供假设。绝对数量受 OCR 和教材版式影响，正式课程范围仍以官方 HSK 大纲为准。

## 1. 样本观察

| 观察 | OCR 证据 | 产品含义 |
|---|---|---|
| 新版低级教材强调情境和跟读 | hsk3 样本贡献 358 个跟读/朗读、163 个角色扮演命中 | 初级课优先短对话、示范、模仿和角色输出 |
| 选择与填空贯穿全部等级 | 选择 2158、填空 1167，均覆盖 23 份文件 | 两者应优先成为稳定共享原语 |
| 高级旧版教材增加复述和造句 | 复述、造句命中主要来自 hsk2 中高级样本 | 中高级课程逐步提高独立语言输出比例 |
| 汉字训练跨多个等级存在 | 汉字栏目覆盖 10 份、笔画书写活动覆盖 19 份文件 | Hanzi Writer 是跨课程能力，不应写进单课页面 |
| 输入形式与题型是正交维度 | 音频刺激 687、图片刺激 135，常与选择/判断同时命中 | audio/image 应建模为 stimulus，不创建独立题型 |
| 新版教材图片和数字资源密度更高 | hsk3 主教材每册约 500-641 个 OCR 图片引用 | 正式课程需要媒体引用和版权门禁，但不能复制教材图片 |

## 2. 初步课程密度假设

### HSK 3.0 一级

- 单课目标控制在 1-2 个可观察能力。
- 建议 6-8 个短步骤，单步只承担一个学习动作。
- 优先音频、图片、选择、跟读、拼合和角色任务。
- 解释保持短，先观察和尝试，再给规则。
- 自由输出使用词块、句框和参考音频支持。

### HSK 3.0 二至三级

- 建议 7-10 个步骤，可包含短篇听读输入。
- 增加填空、排序、短答、近义表达和复述。
- 从逐项提示过渡到部分提示，保留可回看的语言资源。

### 中高级候选

- 建议 8-12 个步骤，但不因文本更长而把整篇内容塞入单步。
- 增加篇章结构、信息整合、语用比较、复述、造句和自由表达。
- 评分边界更重要：确定答案自动判定，自由表达使用 rubric 或人工审核。

## 3. 需要继续验证的问题

- 官方 HSK 3.0 各级的声母、韵母、汉字书写和语法进入顺序。
- 移动端可接受的篇章长度和单课总时长。
- 初级学习者对拼音、汉字和翻译显隐的偏好。
- 角色扮演、跟读和自由输出在无 ASR 环境下的完成标准。
- 高级课程是否需要新的篇章标注组件，而不是扩大 `content-explore`。

这些问题在实际原创课程试产中记录，不通过继续复制教材结构回答。

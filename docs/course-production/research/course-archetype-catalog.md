## 2. 语音与拼音子系列

`pronunciation` 内部按能力形成系列，不继续把拼音等同于四声：

1. 发音基础：音节结构、发音部位、发音方法、气流和送气。
2. 声母：按唇音、舌尖中音、舌根音、舌面音、翘舌音和平舌音分组。
3. 韵母：单韵母、复韵母、前后鼻韵母、`er` 与易混韵母。
4. 音节拼合：合法组合、零声母、`ü` 规则、省写和隔音符号。
5. 声调：四声、轻声、双音节组合和常见变调。
6. 音流：词重音、句重音、停顿、节奏和语调。

具体进入等级和知识点顺序由官方大纲复核，教材只提供教学顺序参考。

## 3. 原型与交互的关系

- 原型规定允许的资源、推荐教学节奏和跨 step 约束。
- 交互原语规定学习动作、状态和完成契约。
- 同一原语可以跨原型使用，例如 `single-choice` 同时服务拼音听辨、词义、听力和阅读。
- 同一原型可以有不同 sequence，不要求机械包含固定七步。
- 检查点通过 assessment policy 编排已学 activity，不拥有专用题型。

## 4. 暂不独立建模的类别

- 文化：使用 `topics` 和 `cultureTags`，由对话、阅读、听力或任务原型承载。
- 图片题：图片是 stimulus，不是课程原型或交互类型。
- 考试题：使用已有 activity 加 assessment policy，不复制交互组件。
- 热身、目标和小结：属于 sequence purpose，不是课程原型。

# HSK 教育市场进入策略（v2）

> 面向对象：准备进入 HSK 教育行业的新进入者
> 竞品情报基础：2026-08-13 调研（HSK University / SuperTest 深挖，引用见文末）
> **v2 更新（基于创始人确认）**：
> 1. **形态**：Web 优先——产品形态与题库稳定后再做 App；目标用户=海外学习者
> 2. **市场**：全球（非英语单一市场）
> 3. **内容**：仅有官方资料 + 第三方出版物，计划用 AI 基于资料生成课程内容
> 核心变化：路线图改为 Web-first + PWA；多语言前移；新增"AI 内容生产线与版权红线"专章

---

## 1. 市场判断：为什么是现在

- **换标红利**：HSK 3.0（2021 新大纲，9 级体系）迁移期，现有玩家都没完成适配——SuperTest 核心资产是 2.0 时代题库 [^1](https://www.cultureyard.net/blog/supertest--hsk-online-review-guide)，HSK University 6 级仍未开放 [^2](https://hskuniversity.com/en)，HelloChinese 只到 HSK 3 [^3](https://apps.apple.com/nl/app/hellochinese-learn-chinese/id1001507516)。**"完整对齐 HSK 3.0"的心智无人占据**。
- **品类空白**：HSKK（口语考试）和 7–9 高级别段无人认真做；AI 实时口语反馈是竞品全缺的能力 [^4](https://www.hskonline.com/)[^5](https://hskuniversity.com/en/ai-tutor)。
- **信任真空**：无任何玩家持有官方授权背书；SuperTest 真题层处于版权灰色地带 [^6](https://www.ipeconomy.cn/anjian/4059.html)。
- **市场规模信号**：SuperTest 150 万+ 用户、200+ 国家 [^7](https://www.hskonline.com/en/about/index)；B 端企业培训 5 万+ 员工 [^8](https://www.hskonline.com/en/corporate/services)——全球付费意愿已被验证。

## 2. 定位与核心能力

**定位声明**：*"为全球 HSK 3.0 考生打造的 AI 口语与备考平台——用 AI 解决'没人陪你练口语'和'新教材内容断层'两个问题。"*

**两条腿**：
- **AI 口语引擎**（差异化武器）：声调级纠错 + HSKK 全题型，竞品全缺
- **AI 内容生产线**（成本武器）：基于官方大纲自动生成原创课程内容，这是你"只有资料没有师资"约束下的解法——**但必须配上版权红线流程（见 §5）**

## 3. 目标用户（全球海外学习者）

**核心画像**：海外成年人，备考 HSK 3.0（尤其 4–6 级 + HSKK），动机=中国留学/求职/商务/兴趣。已在使用 Duolingo/Anki/Pleco。

**区域优先级**（Web-first 让多语言成本低，但别一次铺开）：

| 优先级 | 语言/区域 | 理由 |
|---|---|---|
| P0 | 英语 | 最大付费市场，内容先行 |
| P1 | 西语/葡语 | 拉美中文热，SuperTest 都做了 [^9](https://www.hskonline.com/) |
| P1 | 印尼语/越南语/泰语 | 东南亚来华留学主力，HSK 刚需 |
| P2 | 日语/韩语 | HSK 备考重镇，但竞品也强 |
| P2 | 法语/德语/俄语 | 欧洲非洲增量 |

## 4. 路线图（Web-first 重排）

### Phase 0 — Web 验证（第 1–6 周）
- **免费 HSKK 口语评分器**（录→评→逐音节声调反馈）——验证 AI 引擎 + 获取种子用户
- HSK 3.0 词表闪卡（1–3 级，SRS）——官方大纲词表，零版权风险 [^10](https://www.chinesetest.cn/hsk)
- 第一课 AI 生成内容上线（验证内容管线）
- **验证目标**：① 声调检测准确率；② 1000 种子用户；③ 付费意愿（高级报告收费测试）

### Phase 1 — Web 课程平台（第 3–6 个月）
- 完整课程体系：HSK 1–3 级课程（词汇/语法/课文/练习，AI 管线批量生产 + 人工审核）
- 口语情景对话（HSKK 题型）+ 每日挑战 + 进度系统
- **多语言 i18n 上线（英→西/印尼/越）**
- 分享成绩单裂变 + SEO 内容矩阵启动

### Phase 2 — 题库稳定 + 备考闭环（第 6–12 个月）
- 自研模拟题模考（HSK 1–6 笔试）+ 错题本 + 报告系统（学 SuperTest 闭环 [^1](https://www.cultureyard.net/blog/supertest--hsk-online-review-guide)）
- HSKK 全题型（初/中/高级）；7–9 级内容启动
- 订阅付费上线；**PWA 先行**（Web 达到 App 级体验：离线闪卡/推送/安装）
- B 端试点（1–2 家语言学校）

### Phase 3 — App 与扩展（12 个月+）
- **题库与产品形态稳定后 → 正式 App**（iOS/Android，PWA 用户导流）
- 全 9 级 + 全部目标语言
- 机构/孔子学院渠道合作

**为什么 Web 优先对你正确**：① 无 App 审核周期，快速验证；② 多语言 i18n 成本远低于 App 本地化；③ 你的内容生产管线可以先跑通再铺量；④ HSK University 用 Web 模式也跑通了免费获客 [^2](https://hskuniversity.com/en)。

## 5. 内容策略与版权红线（v2 新增重点章节）

### 5.1 素材合规矩阵

| 素材 | 能否用于课程 | 用法 |
|---|---|---|
| 官方大纲（词表/语法点/话题/考试结构） | ✅ 自由使用 | 考试标准，事实性内容 [^10](https://www.chinesetest.cn/hsk) |
| 官方样题 | 🟡 注明出处 | 教学场景引用，商业分发前确认授权 |
| 第三方出版物（教材） | ⚠️ **只模仿结构，不复制内容** | 参考单元组织/教学法（思想层面）；课文/例句/练习必须原创（表达层面） |
| 官方真题 | ❌ 不做 | 版权归孔子学院总部/出版社 [^11](https://books.google.com/books/about/%E6%96%B0%E6%B1%89%E8%AF%AD%E6%B0%B4%E5%B9%B3%E8%80%83%E8%AF%95%E7%9C%9F%E9%A2%98%E9%9B%86.html?id=W9O20AEACAAJ)，有判例风险 [^2](https://m.21jingji.com/article/20201218/bc07ea2c1a305b3451cb9283683f79cb.html)[^6](https://www.ipeconomy.cn/anjian/4059.html) |

### 5.2 AI 课程生成管线的三道闸门

```
① 输入闸：只喂官方大纲 + 自写教学设计（不喂教材原文）
② 生成闸：LLM 产出原创课文/例句/练习（话题+词表+语法点驱动）
③ 质检闸：人工教学审核 + 相似度查重（与教材文本比对，阈值≥85% 重写）
```

- **为什么必须查重**：LLM 训练数据包含教材原文，可能"看似原创、实为复现"——这是 AI 教育产品最高发的侵权来源
- **成本预估**：一个 3 人小团队 + AI 管线，HSK 一级（150 词）课程约 2–4 周可产出一版
- **质检人**：至少 1 位兼职母语中文老师（AI 生成内容的语法/文化错误必须人工兜底）

### 5.3 把合规变成营销资产
课程页统一标注"Based on the official HSK 3.0 syllabus"，公开承诺"全部内容原创/官方授权"——直接打 SuperTest 真题灰色地带的不透明。

## 6. 技术要点

### 6.1 AI 口语引擎
- ASR 接成熟引擎（Whisper/讯飞/阿里），自研**声调与发音错误检测层**（音节级定位 + 流利度 + 语法纠错）
- HSKK 题型识别：复述一致性、看图说话内容覆盖
- 反馈：声调曲线可视化 + 标准发音对比 + 错误标注
- 数据飞轮：用户录音（明确授权）→ 标注 → 自训评分模型

### 6.2 AI 内容生产线（Web 端天然适合）
- 词表/语法点解析器（从官方大纲结构化）
- 课程生成器（课文/例句/练习 + 音频 TTS）
- 查重服务（教材语料库比对）
- **注意**：TTS 音频质量决定产品质感，建议用高质量中文 TTS（如 Azure/火山/阿里）而非开源廉价方案

## 7. 获客（全球渠道）

1. **多语言 SEO**（Web 的红利）：按区域做长尾——"HSK 3.0 syllabus"、"HSKK practice"、"prueba HSK"、"thi HSK online"（学 HSK University 的内容矩阵 [^12](https://hskuniversity.com/sitemap.xml)）
2. **短视频**：TikTok/YouTube Shorts "老外 HSK 口语挑战"系列（口语评分器天然是素材；HSK University 已验证发帖换免费的裂变有效 [^2](https://hskuniversity.com/en)）
3. **社区**：Reddit r/ChineseLanguage、Discord、各国语言学习社区（西班牙语/印尼语区社群）
4. **免费工具裂变**：口语评分器 + 成绩单分享
5. **渠道**（Phase 2+）：语言学校、留学中介、孔子学院网点
6. **投放**（Phase 2 起）：Google Ads 打 HSK/HSKK 关键词，区域分投

## 9. 风险与应对

| 风险 | 概率 | 应对 |
|---|---|---|
| AI 口语效果不达标 | 中 | Phase 0 先验证再投入；不达标转向内容/题库型 |
| AI 生成内容侵权（隐性复现教材） | 中 | §5.2 三道闸门 + 查重流程，**上线前必须跑通** |
| 生成内容质量差（语法/文化错误） | 高 | 兼职母语老师质检；早期宁可慢 |
| SuperTest 快速跟进 AI 口语 | 中 | 窗口期 6–12 个月；HSKK 专项 + 声调可视化做深 |
| HSK University 补内容打免费战 | 高 | 不打价格战，打"口语能力 + 3.0 完整度" |
| 大厂（Duolingo）认真做 HSK | 低 | 持续监控，无动机绑定 HSK 大纲 |

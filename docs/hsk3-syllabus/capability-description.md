## HSK3.0 考试能力描述

中文水平考试/HSK 是一项国家级标准化考试，重点考查中文作为第二语言的考生在生活、学习和工作中运用中文进行交际的能力。HSK 各等级的能力描述如下：

HSK（一级）能用中文就生活场景进行简单交流。

HSK（二级）能用中文就生活、学习、工作场景进行基本交流。

HSK（三级）能用中文就生活、学习、工作场景进行有效交流。

HSK（四级）能用中文就生活、学习、工作场景进行完整、连贯交流。

HSK（五级）能用中文就工作、学业场景进行准确、恰当交流。

HSK（六级）能用中文就职场、学业、一般专业场景进行丰富、顺畅交流。

HSK（七级）能用中文就职场、一般专业场景、通用学术场景进行规范、流利交流。

HSK（八级）能用中文就职场、一般专业场景、通用学术场景进行得体、深入交流。

HSK（九级）能用中文就职业、专业、学术等各种场景进行精准、深入交流。
